# 👨‍💻 البورتفوليو الشخصي - المهندس محمد (Code Elta6ur)

[![رابط الموقع](https://img.shields.io/badge/Website-code--elta6ur.com-blue?style=flat&logo=google-chrome)](https://code-elta6ur.com/)

هذا المستودع يحتوي على الكود المصدري للموقع الشخصي (Portfolio) الخاص بالمهندس محمد (مؤسس كود التطور). يعرض الموقع الخدمات البرمجية، ومعرض الأعمال الشامل في مجالات تطوير الواجهات الأمامية (Frontend)، وتطوير قوالب بلوجر (Blogger)، وووردبريس (WordPress).

## ✨ المميزات (Features)

- **تصميم عصري ومتجاوب:** يتوافق مع جميع الشاشات والأجهزة بسلاسة عالية.
- **الوضع الليلي والنهاري (Dark/Light Mode):** ميزة مدمجة لتغيير مظهر الموقع لتوفير أفضل تجربة للمستخدم.
- **دعم لغتين (Bilingual):** يحتوي على نسختين للغة العربية `index.html` واللغة الإنجليزية `en.html`.
- **فلترة تصنيفات الأعمال:** تصفية الأعمال والمشاريع برمجياً وعرضها بشكل تفاعلي.
- **أداء عالي:** مبني باستخدام تقنيات الويب الأساسية بدون إطارات عمل ثقيلة لضمان أعلى سرعة تحميل.
- **محسّن لمحركات البحث (SEO):** وسوم وتوصيفات Meta و Open Graph مهيئة لتصدر محركات البحث ومشاركتها بشكل مثالي على وسائل التواصل.

## 🛠️ التقنيات المستخدمة (Tech Stack)

تم بناء المشروع باستخدام التقنيات الأساسية (Vanilla):
- **HTML5**
- **CSS3**
- **JavaScript (Vanilla JS)**

## 🚀 كيفية التشغيل محلياً (Local Setup)

لا يحتاج المشروع لبيئة تطوير معقدة أو خوادم محلية، كونه موقع ثابت (Static Website).

1. قم باستنساخ المستودع (Clone):
   ```bash
   git clone https://github.com/syrmoha/MOHAMMAD-main.git
   ```
2. انتقل إلى مجلد المشروع:
   ```bash
   cd MOHAMMAD-main
   ```
3. قم بفتح ملف `index.html` مباشرة باستخدام أي متصفح ويب، أو يمكنك استخدام إضافة "Live Server" في محرر VS Code لبيئة تطوير أفضل.

## 🗂️ هيكل المشروع (Directory Structure)

```text
├── css/
│   └── style.css       # ملفات التنسيق والألوان العامة
├── js/
│   └── script.js       # الأكواد التفاعلية (الوضع الليلي، الفلترة للمشاريع، ইত্যাদি)
├── img/                # صور المشاريع والملفات المصورة
├── index.html          # الصفحة الأساسية باللغة العربية
└── en.html             # الصفحة الأساسية باللغة الإنجليزية
```
